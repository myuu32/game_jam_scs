# Block of Hope

## Introduction
This game is a 2D horror adventure where players must explore levels and find the correct ending.

## Features
- **Horror Pixel Art Style**: 2D pixel-style visuals.
- **Puzzle Elements**: Challenging levels with great exploration opportunities.

## System Requirements
- **Operating System**: Windows 10 or higher / macOS Mojave or higher
- **Processor**: Intel i5 or equivalent AMD processor
- **Memory**: 4GB RAM
- **Graphics**: NVIDIA GTX 960 / AMD Radeon R9 280 or better
- **Storage**: 500MB available space

## Installation Guide
1. Download the game from releases link.
2. In macOS user you need to press the command key to start the game.
3. Start the game.

## Keyboard&Gamepad
- **WASD / LeftStick**: Move 
- **Left Mouse Button**: Shoot/Recall Block
- **Right Mouse Button**: Teleport Player
- **F Key**: Interact with map objects.
